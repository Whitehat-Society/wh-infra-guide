AWS building blocks 13 terms
Region
A group of AWS data centres in one city.
Everything ran in ap-southeast-1, Singapore.
AZ (Availability Zone)
One isolated data centre inside a region. A fire or outage in one AZ shouldn't affect the others.
3 AZs used: 1a, 1b, 1c.
VPC (Virtual Private Cloud)
Your own private network inside AWS. Nothing reaches it unless a route and a firewall rule allow it.
10.100.0.0/16.
Subnet: public / private
A slice of the VPC inside one AZ. Public subnets can talk to the internet directly. Private subnets have no public IPs.
Load balancers sit in public subnets; the servers run in private ones.
Internet gateway
The VPC's door to the internet, used by the public subnets.
NAT (Network Address Translation) gateway
Lets machines in private subnets open outbound connections without being reachable from outside, like a home router.
One, in AZ 1a, for the whole VPC.
EC2 (Elastic Compute Cloud) instance
A rented virtual machine.
Workers are t3.medium: 2 vCPUs (virtual CPU cores), 4 GiB RAM.
EBS (Elastic Block Store) volume
A network disk attached to one VM. It exists in one AZ only.
Holds the CTFd database and uploads.
S3 (Simple Storage Service)
File storage: objects in buckets.
Database backups and Pulumi state.
ECR (Elastic Container Registry)
AWS's private Docker registry.
Every challenge image lives here.
IAM (Identity and Access Management) role
An AWS identity with permissions. Programs borrow it to get short-lived credentials instead of storing keys.
Route 53
AWS's DNS service.
Hosts whitehats-ctf.com.
CloudWatch · SNS (Simple Notification Service) · Lambda
Metrics and alarms · a notification fan-out topic · a small function that runs when an event arrives.
Alarm → SNS → email and a Lambda that posts to Discord.
How traffic gets in 8 terms
Load balancer
Spreads incoming connections across several servers and skips ones that are down.
NLB (Network Load Balancer)
A layer 4 load balancer: it forwards TCP connections without reading them, so it can't see HTTP hosts or paths.
One for all HTTP, one per pwn challenge.
Ingress controller · NGINX
A reverse proxy that reads HTTP. It decrypts HTTPS, looks at the Host header, sends the request to the right app, and applies rate limits.
2 NGINX pods handle all HTTP traffic.
TLS (Transport Layer Security) certificate · Let's Encrypt
The certificate that makes HTTPS work. Let's Encrypt issues free ones after you prove you control the domain, here by adding a DNS TXT record (DNS-01).
cert-manager does this automatically.
Round-robin
Send each new request to the next server in turn.
How NGINX picks a web challenge pod.
Sticky session · affinity
Keep sending one user to the same server, usually by setting a cookie.
Not configured anywhere here.
Rate limit
A cap on requests per second per key, usually the client's IP. Excess requests get an error.
20 req/s per IP on web challenges, else 503.
Source IP · proxy protocol
The address a server believes the client has. Behind an NLB it can be the NLB's own address unless proxy protocol passes the real one along.
Not enabled here.
Kubernetes 19 terms
Container · image
An image is a packaged app plus its filesystem, built from a Dockerfile. A container is one running copy of it.
k8s (Kubernetes) · EKS (Elastic Kubernetes Service)
Software that runs containers across many machines and restarts them when they die. EKS is AWS's managed version: AWS runs the control plane.
Cluster wh-2026-eks.
Cluster · node
The whole Kubernetes setup · one machine (an EC2 VM) in it.
3 nodes at deploy, 4 by teardown.
Control plane · API server
The brain of the cluster. It stores what should be running; every tool, including kubectl, talks to it.
Pod
The smallest thing Kubernetes runs: one or more containers sharing an IP address.
One copy of a challenge = one pod.
Deployment · replicas
"Keep N identical pods running." N is the replica count. A pod that dies is replaced.
Web challenges: 2 replicas. Pwn: 3.
Service
A stable internal name and IP in front of a group of pods. Type LoadBalancer makes AWS create an NLB for it.
ctfd:8000, loop:7331.
Ingress
A rule like "host X goes to Service Y", read by NGINX.
xssive-login.challenges.whitehats-ctf.com → xssive-login.
Namespace
A folder that groups resources. It doesn't isolate them by itself.
ctfd, challenges-web, challenges-tcp.
DaemonSet
Runs one pod on every node.
Network, log and metrics agents.
CronJob
Runs a pod on a schedule.
Hourly backup, 5-minute healthcheck.
PVC (PersistentVolumeClaim) · RWO (ReadWriteOnce)
A pod's request for a disk. ReadWriteOnce means only one node can mount it.
Why CTFd runs as a single pod.
Secret
A Kubernetes object that hands passwords and tokens to pods.
Requests · limits
What a pod reserves (used to find room for it) · the most it may use. 500m (500 millicores) is half a CPU core; 128Mi (mebibytes) is 128 MiB of RAM. Over the memory limit, the container is killed (OOMKilled: Out Of Memory).
Challenge pods: 100m / 128Mi requested, 500m / 512Mi max.
Scheduler · Pending
The scheduler picks a node for each new pod. A pod that fits nowhere waits in Pending.
HPA (HorizontalPodAutoscaler) · Cluster Autoscaler
HPA adds pods when they're busy (not used here). Cluster Autoscaler adds nodes when pods are Pending (used here).
PDB (PodDisruptionBudget)
Stops Kubernetes from evicting a pod on purpose, for example while draining a node.
Set on CTFd and MariaDB.
Controller
A program in the cluster that watches Kubernetes objects and creates the real thing to match.
LB controller → NLBs, ExternalDNS → DNS records, cert-manager → certificates.
IRSA (IAM Roles for Service Accounts)
How a pod gets an IAM role: the role is tied to the pod's service account.
The backup job writes to S3 this way.
Tools in this repo 8 terms
IaC (Infrastructure as Code)
Infrastructure written down in files and applied by a tool, instead of clicked together in the AWS console.
Terraform
IaC tool. Keeps a state file of what it created; apply creates or updates, destroy removes.
Builds the AWS side: utils/eks.
Pulumi
IaC written in a real programming language, Go here.
Deploys CTFd and the challenges onto the cluster.
Helm · chart
A package manager for Kubernetes. A chart is an installable app with settings.
NGINX, cert-manager and the other controllers.
kubectl (kube control)
The command line client for the Kubernetes API.
builder.py · ctfcli (CTFd command line tool)
This repo's script that builds challenge images and deploys them · CTFd's tool that loads challenge.yml into CTFd.
connection_info
The CTFd field that shows players a URL or an nc command.
Same value for every player.
socat (SOcket CAT)
Listens on a port. With fork, it starts a fresh process for each connection: the classic pwn hosting setup.
Every pwn container.
