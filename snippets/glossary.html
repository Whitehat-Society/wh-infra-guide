AWS building blocks 13 terms
Region
A group of AWS data centres in one city.
Everything in this system runs in ap-southeast-1, which is Singapore.
AZ (Availability Zone)
One isolated data centre inside a region, built so that a fire or power cut in one zone doesn't affect the others.
The system uses three zones, 1a, 1b and 1c.
VPC (Virtual Private Cloud)
Your own private network inside AWS. Nothing can reach it unless a route and a firewall rule allow it.
This system's network uses the addresses 10.100.0.0/16.
Subnet: public / private
A slice of the VPC inside one zone. Public subnets can talk to the internet directly, while private subnets have no public addresses at all.
The load balancers sit in public subnets, and the servers run in private ones.
Internet gateway
The VPC's door to the internet, which the public subnets use.
NAT (Network Address Translation) gateway
A device that lets machines in private subnets open connections to the internet without becoming reachable from outside, much like a home router.
There is one, in zone 1a, for the whole VPC.
EC2 (Elastic Compute Cloud) instance
A rented virtual machine.
The cluster's computers are t3.medium machines, each with 2 virtual processor cores and 4 GiB of memory.
EBS (Elastic Block Store) volume
A network disk attached to one virtual machine, which exists in only one zone.
These disks hold the CTFd database and the uploaded files.
S3 (Simple Storage Service)
AWS's file storage, where files are kept as objects inside buckets.
The system keeps its database backups and Pulumi's records here.
ECR (Elastic Container Registry)
AWS's private registry for container images.
Every challenge image is stored here.
IAM (Identity and Access Management) role
An AWS identity with a set of permissions. Programs borrow a role to get short-lived credentials, so they never need to store keys.
Route 53
AWS's DNS service.
It holds the DNS records for the club's domain.
CloudWatch · SNS (Simple Notification Service) · Lambda
CloudWatch collects measurements and raises alarms, SNS passes each notification on to everyone subscribed to it, and Lambda runs a small function whenever an event arrives.
An alarm goes to SNS, which sends an email and also starts a Lambda function that posts to Discord.
How traffic gets in 8 terms
Load balancer
A service that spreads incoming connections across several servers and skips any server that is down.
NLB (Network Load Balancer)
A load balancer that forwards TCP connections without reading them, which means it can't see web addresses or paths. This kind is also called a layer 4 load balancer.
There is one for all web traffic, and one for each pwn challenge.
Ingress controller · NGINX
A program that reads web requests on behalf of the apps behind it. It decrypts HTTPS, looks at the name the visitor typed, sends the request to the right app, and applies the request limits.
Two NGINX pods handle all of the system's web traffic.
TLS (Transport Layer Security) certificate · Let's Encrypt
The certificate is the file that makes HTTPS work. Let's Encrypt issues certificates for free once you prove that you control the domain, which this system does by adding a DNS record (a method called DNS-01).
cert-manager requests and renews the certificates automatically.
Round-robin
Sending each new request to the next server in turn.
This is how NGINX picks a pod for a web challenge.
Sticky session · affinity
Sending a user to the same server every time, usually by setting a cookie.
This isn't set up anywhere in this system.
Rate limit
A cap on how many requests per second one client may send, usually counted by the client's address. Requests over the cap get an error.
Each web challenge allows 20 requests a second from each address and answers 503 beyond that.
Source IP · proxy protocol
The address a server believes the client has. Behind a load balancer this can turn out to be the load balancer's own address, unless the load balancer is set to pass the real one along.
The fixed code sets preserve_client_ip on the web load balancer, so NGINX and CTFd see each player's real address.
Kubernetes 19 terms
Container · image
An image is a packaged app together with its files, built from a Dockerfile, and a container is one running copy of an image.
k8s (Kubernetes) · EKS (Elastic Kubernetes Service)
Kubernetes is software that runs containers across many machines and restarts them when they stop. EKS is AWS's managed version of it, in which AWS runs the control plane for you.
The cluster is named after the event, for example wh-2026-eks.
Cluster · node
The cluster is the whole Kubernetes setup, and a node is one machine in it, which here is an EC2 virtual machine.
WH-2026 started with 3 nodes and had 4 by the time it was torn down.
Control plane · API server
The brain of the cluster. It stores what should be running, and every tool, kubectl included, talks to it.
Pod
The smallest thing Kubernetes runs, made of one or more containers that share an address.
One copy of a challenge is one pod.
Deployment · replicas
An instruction to keep a certain number of identical pods running, where that number is the replica count. When a pod dies, Kubernetes replaces it.
Web challenges run 1 replica by default, and pwn challenges run 3.
Service
A fixed internal name and address in front of a group of pods. A Service of the LoadBalancer type also makes AWS create a load balancer for it.
For example, ctfd listens on port 8000 and loop on port 7331.
Ingress
A rule such as "requests for name X go to Service Y", which NGINX reads.
xssive-login.challenges.whitehats-ctf.com goes to the xssive-login Service.
Namespace
A folder that groups related resources. On its own it doesn't keep them apart from other namespaces.
The system uses ctfd, challenges-web and challenges-tcp.
DaemonSet
An object that runs one pod on every node.
The network, log and metrics agents run this way.
CronJob
An object that runs a pod on a schedule.
The hourly backup and the 5-minute health check are CronJobs.
PVC (PersistentVolumeClaim) · RWO (ReadWriteOnce)
A PVC is a pod's request for a disk. ReadWriteOnce means that only one node can use the disk at a time.
This is why CTFd runs as a single pod.
Secret
A Kubernetes object that hands passwords and tokens to pods.
Requests · limits
A request is what a pod reserves, which Kubernetes uses to find room for it, and a limit is the most it may use. 500m (500 millicores) is half a processor core, and 128Mi is 128 mebibytes of memory. A container that goes over its memory limit is stopped, which Kubernetes reports as OOMKilled (out of memory).
Challenge pods request 100m and 128Mi, and may use at most 500m and 512Mi.
Scheduler · Pending
The scheduler picks a node for each new pod. A pod that doesn't fit anywhere waits in the Pending state.
HPA (HorizontalPodAutoscaler) · Cluster Autoscaler
An HPA adds pods when they get busy, and this system doesn't use one. The Cluster Autoscaler adds nodes when pods are stuck in Pending, and this system does use it.
PDB (PodDisruptionBudget)
A rule that stops Kubernetes from removing a pod on purpose, for example while a node is being emptied.
CTFd and MariaDB both have one.
Controller
A program in the cluster that watches Kubernetes objects and creates the real thing to match them.
The load balancer controller creates load balancers, ExternalDNS creates DNS records, and cert-manager creates certificates.
IRSA (IAM Roles for Service Accounts)
The way a pod gets an IAM role, by tying the role to the pod's service account.
The backup job writes to S3 this way.
Tools in this repo 8 terms
IaC (Infrastructure as Code)
Infrastructure written down in files and applied by a tool, rather than clicked together in the AWS console.
Terraform
An infrastructure-as-code tool that keeps a state file of what it created. Its apply command creates or updates resources, and destroy removes them.
It builds the AWS side of the system from utils/eks.
Pulumi
An infrastructure-as-code tool in which you write the description in a real programming language, which is Go here.
It deploys CTFd and the challenges onto the cluster.
Helm · chart
Helm is a package manager for Kubernetes, and a chart is an installable app together with its settings.
NGINX, cert-manager and the other controllers are installed as charts.
kubectl (kube control)
The command-line tool for talking to Kubernetes.
builder.py · ctfcli (CTFd command line tool)
builder.py is this repository's script that builds the challenge images and deploys them, and ctfcli is CTFd's own tool that loads each challenge.yml into CTFd.
connection_info
The CTFd field that shows players a web address or an nc command.
Every player sees the same value.
socat (SOcket CAT)
A program that listens on a port. With the fork option it starts a fresh process for each connection, which is the classic way to host a pwn challenge.
Every pwn container uses it.
