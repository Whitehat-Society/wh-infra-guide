# Your computer: overview

## The goal

By the end of this section, your own computer can run every command in the rest of the guide. You'll have a terminal that understands Linux commands, you'll know the few terminal skills the guide relies on, and every tool will be installed and checked. Nothing here touches AWS or costs anything.

## The order

| Page | What you'll have afterwards | Why it comes here |
|---|---|---|
| [Open a terminal](terminal.md) | A Linux terminal. On Windows this is Ubuntu, running inside WSL. | Every later step is typed into it. |
| [Terminal basics](terminal-basics.md) | The habits of running commands, moving between folders, editing files and reading errors. | The install page assumes them. |
| [Install the tools](pc.md) | Docker, the AWS CLI, Terraform, Pulumi, kubectl, Go and the Python tools, with one command that checks them all. | Sections 3 to 7 use these tools. |

You're done with this section when the check at the bottom of [Install the tools](pc.md#check-it-worked) prints no `MISSING` lines and ends with `Hello from Docker!`.

**Next:** [Open a terminal](terminal.md).
